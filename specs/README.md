# Frontend Specs

Thư mục này lưu quyết định kỹ thuật và hợp đồng của frontend.

## Danh mục

- `architecture.md`: cấu trúc source và quy tắc phụ thuộc.
- `api-conventions.md`: quy ước gọi API và xử lý lỗi.
- `auth.md`: xác thực, phân quyền và bảo vệ route.
- `weekly-plan.md`: phạm vi feature kế hoạch tuần.
- `daily-plan.md`: phạm vi feature kế hoạch ngày.

Mỗi feature mới phải cập nhật spec liên quan trước hoặc cùng pull request.
